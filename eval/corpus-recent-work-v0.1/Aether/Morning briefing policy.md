# Morning briefing policy

The full daily note is the main deliverable. The short message is only the
at-a-glance summary.

Selection rules:

- default to omission;
- include only clearly material information that is new since the last
  delivered brief or same-day update;
- omit an entire section when it has no genuine new content;
- do not repeat an item merely because it remains important or appears in
  multiple publications;
- omit ski coverage until Thanksgiving weekend 2026 unless the owner asks
  sooner;
- if a standing tracker has no material delta, keep it out;
- include an automation section only for meaningful active failures;
- never guess when a source is unavailable or stale.

Delivery rules:

- create or update today's note first;
- update the home-page pointer to today's note;
- run the sync step;
- only then return the final short summary;
- do not emit progress updates, placeholders, drafts, or orchestration notes.
